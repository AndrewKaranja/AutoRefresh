Privacy

Auto Refresh collects nothing, transmits nothing and sells nothing. There is no analytics, no telemetry and no remote code. Everything below is verifiable in the source.

  • The tabs you are refreshing live in chrome.storage.session, which is held in memory and never written to disk.
  • Your site rules and settings live in chrome.storage.sync, which syncs through your own Google account — not through any server of ours.
  • Page monitoring hashes the watched text locally to compare it against the previous load. Page content is never transmitted.

Why each permission is needed

PermissionWhat it is for
storageSaves your intervals, rules and the current refresh state on this device.
alarmsSchedules reloads of 30 seconds or longer. It is the only timer a Manifest V3 service worker can rely on, because Chrome shuts the worker down when idle.
tabsReads the URL and title of the tab you chose to refresh, so the right tab is reloaded and matched against your rules.
scriptingInjects the refresh agent into pages you explicitly enabled — this is what provides sub-30-second timing, scroll memory and change detection.
activeTabLets you point at a region of the current page to watch, using only the tab you invoked the extension on.
notificationsShows a desktop alert when a watched page changes. Opt-in per job.
offscreenPlays the alert sound. Manifest V3 service workers have no DOM and cannot play audio directly.
host accessRequested at runtime, one site at a time, and only for features that must read the page.

Known limits

  • Intervals under 1 second are not offered: Chrome throttles timers in background tabs to about one per second, so anything faster would only hold while the tab is in front.
  • A page with unsaved text in a form shows Chrome's "Leave site?" dialog. Auto Refresh detects this and waits rather than fighting it.
  • Jobs do not survive a browser restart, because every tab gets a new id. Use a site rule to have them restart themselves.
  • Very short intervals can get you rate-limited or temporarily blocked by a site. Random intervals help; below 5 seconds, be careful.
