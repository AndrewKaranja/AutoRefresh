Auto Refresh

Reload any Chrome tab on your schedule — and find out when the page actually changed.

What it does

Interval presets + custom5 seconds to 24 hours, one tap
Random intervalsVary each reload, so the pattern looks less automated
Hard reloadTrue cache bypass
Scroll memoryReturns you to where you were
Page-change alertsPick a region, get a notification and a sound when it changes — free
Ignore-regexHide clocks and rotating ads so they don't count as changes
Site rules"Always refresh this site", surviving a browser restart
Smart scopingNavigating away pauses — it never starts hammering the new page

Installs with no permission warnings

Reloading a tab does not require permission to read it, so a basic refresh needs no site access at all. Auto Refresh asks for a single site only when you switch on something that genuinely has to read the page — sub-30-second intervals, scroll memory, or change monitoring — and it asks at the moment you click Start on that site.
